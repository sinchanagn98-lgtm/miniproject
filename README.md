
# 🌱 AgriSmart

## AI-Based Crop Recommendation and Farming Guidance System

### 1. Introduction
AgriSmart is a machine learning based agricultural
application designed to help farmers select suitable
crops according to soil and weather conditions.

### 2. Objectives
- Recommend suitable crops.
- Analyze soil nutrients.
- Consider weather conditions.
- Provide crop growing information.
- Display water and fertilizer guidance.

### 3. Technologies Used
- Python
- Pandas
- Scikit-learn
- Random Forest
- Streamlit

### 4. Machine Learning
Random Forest Classification is used to predict
suitable crops based on agricultural inputs.

### 5. Features
- Interactive farmer input form
- Top three crop recommendations
- Crop information
- Farming guidance
- Weather record display

### 6. Dataset
Crop_recommendationV2.csv

### 7. Installation

Install the required libraries:

pip install -r requirements.txt

### 8. Train the Model

python -m model.train_model

### 9. Run the Application

streamlit run app.py

### 10. Future Enhancements
- Live weather API integration
- Location-based crop recommendations
- Crop disease detection
- Market price information
- Fertilizer recommendation
- Multilingual farmer support

### 11. Disclaimer
Recommendations are based on the available
training dataset and should be verified
with local agricultural experts.
